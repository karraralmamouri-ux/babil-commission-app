# خطة الاختبار

## المبادئ

- قواعد الحساب تختبر كوحدات خالصة مستقلة عن DOM.
- RLS تختبر بحساب فعلي لكل دور، وليس فقط service role.
- الترحيل يثبت بالمجاميع والبصمات وإعادة التشغيل.
- التغييرات المرئية تختبر RTL والهاتف والكمبيوتر.

## اختبارات الحساب

- الكميات: 0، أعداد موجبة، وقيم غير صالحة.
- حدود الشرائح: 0، 1، 200، 201، 400، 401.
- P35/P45/P65 منفردة ومختلطة.
- اختيار تلقائي ويدوي.
- المبلغ المستحق والمدفوع والمتبقي.
- منع السالب وتجاوز المستحق.
- عدم تغير شهر مؤرشف بعد تغيير أسعار شهر آخر.

## الأشهر

- يناير بعد ديسمبر.
- الشهر السابق عبر سنة جديدة.
- إنشاء شهر من الشهر المفتوح لا من ساعة الجهاز.
- ترتيب الفترات زمنياً.
- منع تعديل الفترة المقفلة.

## الاستيراد والتصدير

- CSV عربي وإنجليزي وBOM واقتباسات وفواصل وأسطر فارغة.
- XLSX بأعمدة معروفة ومفقودة وأنواع خاطئة.
- أسماء/أكواد مكررة وتعارض المنطقة.
- preview دون كتابة، ثم import idempotent.
- تطابق التصدير مع البيانات والمجاميع.

## الأدوار والأمان

- admin، accountant، monitor، viewer لكل عملية وجدول.
- تعطيل المستخدم أثناء الجلسة.
- منع تغيير الدور ذاتياً.
- رفض استدعاء Edge Function بلا JWT أو بدور غير مناسب.
- منع تعديل audit والفترة المقفلة.

## اختبارات التكامل وE2E

- المعاينة المركزية تقرأ كل صفحات `commission_months` و`commission_rows` بجلسة المستخدم وRLS، وترفض القيم السالبة أو الصفوف اليتيمة أو المدفوع فوق المستحق قبل العرض.
- اختيار شهر مركزي محفوظ ثم فتحه للتجهيز يحتفظ بالشهر المختار ويمكّن تعديله دون كتابة مركزية قبل الاعتماد.
- صلاحيات الأدمن لإدارة المستخدمين والنسخ الاحتياطي تعمل من العرض المركزي، بينما يظل تعديل العمولة داخل وضع التجهيز.
- جسم اعتماد الشهر يتضمن التير المطبق ووضعه وأساس مجموعة التير وحساب `parent`، وتغطي اختبارات المهاجرة قيود الدور والصرف والحذف.
- تقرير Excel يحتوي Summary وCommissions وComparison وSettings، مع صيغ كمية ومستحق ومتبقي قابلة للمراجعة.
- أثناء المعاينة تختفي أو تتعطل كل مسارات الكتابة، ثم يعيد الرجوع الشهر والحالة المحلية وعلامة التعديلات غير المحفوظة.
- تسجيل الدخول والخروج وانتهاء/تحديث الجلسة.
- إنشاء وكيل وفترة وأسعار وعمولة ودفعة.
- اعتماد وقفل الشهر.
- إدارة المستخدمين عبر `admin-users`.
- انقطاع الشبكة ورسائل الخطأ العربية وعدم فقدان الإدخال.

## بوابة التسليم

كل PR يذكر الأوامر المنفذة والنتائج. إن تعذر اختبار مطلوب، يوثق كخطر ولا يوصف التغيير بأنه مكتمل إنتاجياً.

## خط الأساس الآلي الحالي

يشغل الأمر التالي اختبارات توصيفية على JavaScript الفعلي المضمّن في `index.html` دون تنفيذ المصادقة أو أي طلب شبكة:

```text
npm test
```

تشمل الاختبارات انتقال ديسمبر/يناير، والترتيب الزمني، وإنشاء الشهر التالي من الفترة المفتوحة بدلاً من تاريخ الجهاز.
